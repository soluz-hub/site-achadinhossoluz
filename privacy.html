Política de Privacidade - Achadinhos Soluz

Esta Política de Privacidade descreve de forma clara como o aplicativo Achadinhos Soluz trata as informações necessárias ao seu funcionamento.

1. Coleta de Dados

O aplicativo acessa apenas as informações da própria conta do usuário (o dono do bot) para criar e agendar Pins e mensagens. Não são coletados dados de visitantes ou de terceiros.

2. Uso dos Dados

Os dados são usados exclusivamente para automatizar a publicação de conteúdo e gerar métricas de cliques. Nenhum dado é vendido, alugado ou compartilhado com terceiros.

3. Segurança

Os tokens de acesso (API do Pinterest, Telegram, etc.) e chaves de API são armazenados localmente de forma criptografada no banco de dados do usuário.

4. Direitos do Usuário

O usuário pode revogar o acesso do aplicativo a qualquer momento nas configurações de sua conta no Pinterest.
